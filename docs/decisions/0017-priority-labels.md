# 0017. Priority labels

## Context

Issues need a light way to rank work.

## Decision

Use three priority labels: `p0` fix before build, `p1` needed, `p2` later.

## Consequences

- An issue has at most one priority.
- Triage lists open issues with none.

Accepted by the owner on 2026-11-05.
