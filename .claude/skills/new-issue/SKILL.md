# New issue

1. Search open issues for the topic. If a match exists, comment there and stop.
2. Pick the form: `bug`, `task`, `finding` or `decision`. Use `decision` when the owner must choose.
3. Create the issue from that form. Keep the title in the `ctype(area): subject` shape.
4. Set exactly one type label from `docs/reference/taxonomy.md`.
5. Set one or more `area:` labels and a milestone. Use `Backlog` when unsure.
6. Add the `agent-filed` label. Put the session link in the body.
7. Add `needs-human` when the issue is a decision.
8. Attach the issue to its tracker as a sub-issue. Pass the issue `id`, not the number.
9. Report the issue number and link.

Never file private names, hosts or IPs. See `AGENTS.md` for hygiene rules.
